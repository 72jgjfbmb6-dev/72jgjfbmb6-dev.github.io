# Личный сайт

Одностраничный статический сайт-визитка специалиста: контакты, адрес и
интерактивная карта. Опубликован на GitHub Pages по адресу
`https://72jgjfbmb6-dev.github.io`.

Собран на чистом HTML, CSS и JavaScript — без фреймворков, сборщиков и бэкенда.

## Структура

```
index.html            главная и единственная страница
404.html              страница «не найдено» со ссылкой на главную
assets/
├── css/style.css     стили
├── js/map.js         инициализация карты (координаты заданы константами)
├── img/favicon.svg   фавикон
└── vendor/leaflet/   локальная копия Leaflet 1.9.4 (leaflet.js, leaflet.css, images/)
.nojekyll             отключает обработку Jekyll на GitHub Pages
```

## Карта

Карта построена на [Leaflet](https://leafletjs.com/) **1.9.4** (стабильная версия)
с тайлами OpenStreetMap. Библиотека хранится локально в `assets/vendor/leaflet/`,
CDN не используется. Под картой есть ссылка «Открыть на OpenStreetMap», которая
работает и без JavaScript.

Координаты точки заданы константами в `assets/js/map.js` — геокодирование при
загрузке страницы не выполняется.

## Как обновить контакты

Все данные вписаны прямо в разметку:

- телефон, email, адрес и часы приёма — в `index.html`;
- координаты карты, имя и адрес в попапе маркера — константы в начале
  `assets/js/map.js`;
- инициалы в аватаре — в блоке `.avatar` в `index.html` (при появлении фото
  заменить на `<img>` с атрибутом `alt`).

После правок закоммитьте изменения и запушьте в ветку `main` — GitHub Pages
пересоберёт сайт автоматически.

## Безопасность

- Политика безопасности (CSP) задана через meta-тег в `<head>`: единственный
  внешний ресурс — тайлы OpenStreetMap, всё остальное отдаётся с того же домена.
  Inline-скриптов и inline-стилей нет.
- GitHub Pages не позволяет задавать HTTP-заголовки, поэтому директива
  `frame-ancestors` (защита от встраивания в чужой iframe через `X-Frame-Options`)
  недоступна — в meta-варианте CSP она не действует. Для статической страницы без
  форм и личного кабинета это допустимый риск.
- В репозитории нет токенов, паролей и API-ключей.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.
